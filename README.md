# AI Based Web Application for Vascular Dementia Caregiver Support

CogniCare's research project website. This is a static HTML site; no package installation or build is needed.

## Run locally

Install Git and Python 3, then run:

```sh
git clone https://github.com/dilukaathukorala/website-research.git
cd website-research
python3 -m http.server 8000
```

On Windows, use `py -m http.server 8000` if `python3` is unavailable.

Open http://localhost:8000 in your browser. Press Ctrl+C in the terminal to stop the server.

Google Drive documents require internet access and the appropriate sharing permissions. The contact form also requires internet access to submit.
